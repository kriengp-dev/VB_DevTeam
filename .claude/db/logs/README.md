# db/logs/ — sqlcmd Output (not committed)

Output files from `sqlcmd -o` runs (for example `V001.log`). They can contain data and server details, so they are **never committed**: the folder's `.gitignore` ignores everything except this README and `.gitignore` itself.

- Written only by `db-developer`.
- Quote the relevant lines in your final report's *Verification*; do not rely on the log file as the record.
- Delete old logs freely; they are not part of the deliverable.
